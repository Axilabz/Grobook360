📗 GroBook 360 — Manager User Flow

Role: MANAGER
Index Owner Manager Salesperson
Manager operates nearly every module day-to-day — Customers, Suppliers, Products, Inventory, the full Sales and Purchase document chains, Payments, Payroll, and view/prepare access to Accounting/GST/Reports/Analysis. Three things Manager cannot do (RBAC Alignment Phase): reverse an Accounting journal or manage account mappings, export prepared GST data, and see the Role & Permission catalogue (Owner-only "User Permission" menu item). User Management is view-only, and Business Profile/Configuration are view-only.
