📙 GroBook 360 — Salesperson User Flow

Role: SALESPERSON
Index Owner Manager Salesperson
Salesperson is scoped to day-to-day field-sales work. Full create/edit on Customers (no deactivate), view-only on Products and Inventory, the full day-to-day lifecycle on every Sales document (Estimate → Sales Order → Delivery Challan → Sales Invoice → Return → Credit/Debit Note) except the single highest-commitment action on each one (Confirm / Post / Convert), which stays Owner/Manager-only. Can record and edit Customer Receipts but never post or reverse one. Sees only Dashboard/Sales/Inventory reports and, in Analysis, only their own row in Sales-by-User. Zero access to Suppliers, every Purchase document, Supplier Payments, Accounting, GST, Payroll, Users, Business Profile/Configuration, and Role & Permission Configuration — none of those modules appear in this flow at all.
