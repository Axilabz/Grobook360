🧭 GroBook 360 — Interactive User Flows by Role

Three self-contained, interactive step-by-step guides — one per tenant role — covering every module, sub-module and feature this app exposes, built directly from the backend's own permission catalogue (backend/app/core/permissions.py). Each page only shows the modules and actions that role can actually perform; pick a role below and click through each module with Next/Back.
👑

Owner

Full access to every module, including user management, tenant configuration, journal reversal, GST export and the role/permission catalogue.
🧑‍💼

Manager

Runs day-to-day operations across almost every module — view/prepare-only on Accounting & GST's higher-risk actions, view-only on Users & Configuration, no Role/Permission access.
🧑‍🔧

Salesperson

Field-sales scoped: the day-to-day Sales document chain, Customers, view-only Products/Inventory, drafting Customer Receipts — zero Purchase, Accounting, GST, Payroll or Admin access.
Regenerate by editing assets/modules-data.js whenever backend/app/core/permissions.py changes.
