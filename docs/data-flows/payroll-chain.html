Atomic: locks run → requires CALCULATED + employee_count>0 → assigns payslip_number per record (format PAYSLIP-{FY}-0001) → calls AccountingPostingService → flips statuses.

Database

Run status → FINALIZED, stores accounting_posting_reference; each record → FINALIZED; period → FINALIZED.

Side-Effects
Accounting

AccountingPostingService.post_payroll_run(total_gross, total_deductions, total_net, ...) — DR Salary Expense (gross) / CR Salary Deductions Payable (if >0) / CR Salary Payable (net). Consolidated — one journal per RUN, never per employee. No PF/ESI/TDS line exists anywhere.

Zero Stock Ledger or GST interaction anywhere in this file.
